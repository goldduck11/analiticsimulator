# Фронтенд

Next.js (App Router), React 19, Tailwind, Zustand, Recharts. Функциональность: аутентификация, дашборд, задачи, отправка ответов и просмотр результатов; обмен с сервером через REST, базовый URL задаётся в `NEXT_PUBLIC_API_URL`.

## Требования

- **Node.js** версии 20 и выше.
- Работающий экземпляр **backend**; по умолчанию ожидается `http://localhost:8080`. Переопределение через переменные окружения описано ниже.

Для зависимостей зафиксирован **Yarn** (`yarn.lock`). Аналогичные команды доступны в **npm** (`npm install`, `npm run dev`).

## Запуск в режиме разработки

```bash
cd client
cp .env.example .env.local
yarn install
yarn dev
```

После запуска dev-сервера интерфейс доступен по адресу http://localhost:3000 (порт Next.js по умолчанию).

## Переменные окружения

Локальная конфигурация: копирование `.env.example` в `.env.local` с последующим изменением при необходимости.

| Переменная | Значение по умолчанию | Назначение |
|------------|------------------------|------------|
| `NEXT_PUBLIC_API_URL` | `http://localhost:8080` | Базовый URL API; завершающий слэш не требуется (обрезается в коде). |

Переменные с префиксом `NEXT_PUBLIC_` включаются в клиентский бандл; секретные данные в них не помещаются.

## Скрипты `package.json`

| Команда | Назначение |
|---------|------------|
| `yarn dev` | Режим разработки, hot reload. |
| `yarn build` | Продакшен-сборка. |
| `yarn start` | Запуск после `build`. |
| `yarn lint` | Проверка ESLint. |
| `yarn format` | Форматирование Prettier (запись в файлы). |
| `yarn format:check` | Проверка форматирования без изменения файлов. |

## Структура каталогов

| Каталог / файл | Содержание |
|----------------|------------|
| `app/` | Маршруты App Router: главная, `(auth)`, `dashboard`, `tasks/[id]`, `results/[submissionId]`. |
| `components/` | Компоненты UI, в том числе `ui/` на базе Radix, лейаут, дашборд, задания. |
| `lib/api/client.ts` | HTTP-клиент к API, сессия в `localStorage`, задачи и отправка ответов. |
| `store/` | Хранилища Zustand (`auth`, задачи, прогресс). |
| `types/` | Типы TypeScript для контрактов с API. |

Изменение базового URL и логики запросов выполняется преимущественно в `lib/api/client.ts`.

## Docker

В каталоге `client` расположен `Dockerfile` (образ Node 20, установка зависимостей через **npm**, команда по умолчанию: `npm run dev`).
